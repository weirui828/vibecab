# Design concepts (2026-11-10)

Three directions for how VibeCab could look and feel, as working prototypes. Open a file in a browser; each one
plays the whole loop: comment, agree, Update.

| File                 | Direction                                                                                                                                                                                |
| -------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `a-cable-line.html`  | A session is a cable line across the tundra, each version a station. A comment is a ticket; agreeing punches it; an Update is the cab leaving for the next station. Day and polar night. |
| `a-line-map.html`    | The home page for A: every session once, as a line, with the cab where the work stands.                                                                                                  |
| `b-resonance.html`   | From "vibe". A string runs beside the draft and sounds when you touch a thread; two waves show whether you and the agent are in tune; a version is a take.                               |
| `c-field-notes.html` | The draft is print, everything added is by hand: pencil in the margin, the agent on a sticky note, a rubber stamp to agree, a page turn for an Update.                                   |

These are sketches, not app code: nothing here is wired to the engine.

## A + B together

- `ab-resonant-line.html` — the session page after Wei's feedback on A and B. The cable is the string: open threads
  are beads that keep it humming, agreeing rings the bead and slides it to the cab. The cab is the C of the logo
  (the mark's own outline, clipped), hung on the cable point for point, with an ease out, cruise and brake and a
  pendulum swing from its own acceleration. Colours are Tundra palette steps only.
